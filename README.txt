CNA OCIAN — SITE ORGANIZADO

Estrutura:
- index.html: estrutura da apresentação
- css/style.css: todo o CSS separado
- js/slides.js: conteúdo e caminhos das imagens
- js/app.js: navegação, progresso, teclado, toque e tela cheia
- img/: imagens dos 12 slides + personagem do slide final

Slide final:
13 — “GRANDES RESULTADOS NÃO ACONTECEM POR ACASO. ELES SÃO PLANEJADOS.”

Como usar:
1. Extraia a pasta.
2. Abra index.html em um navegador moderno.
3. Use ←/→, espaço, PageUp/PageDown ou os botões na tela.
4. No celular, deslize para trocar de slide.
5. O botão ⛶ ativa tela cheia.

Observação: o projeto não depende de bibliotecas externas; basta manter a estrutura de pastas.
